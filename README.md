# Mi Cuenta Personal – Royen VIP

App personal offline para:
- Estudiante de Ingeniería de Sistemas (UNHEVAL)
- Fundador de Royen VIP (startup tipo Uber)
- Trading

## Cómo usar

1. Abre `index.html` con Chrome
2. En Chrome → menú (3 puntos) → "Añadir a la pantalla de inicio"
3. Listo. Funciona offline.

## Estructura

- `index.html` → Estructura principal
- `css/style.css` → Estilos (tema oscuro)
- `js/app.js` → Lógica de la aplicación
- `js/data.js` → Datos iniciales (horario, categorías, etc.)
